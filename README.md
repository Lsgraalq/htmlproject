# AutoExpress — commercial landing page

> **Created: 2024** — my first commercial web project (client landing page).

A responsive marketing **landing page** built for a real client — **AutoExpress**, a service for importing cars from the USA to Ukraine ("авто из США под ключ"). This was my first paid/commercial project: taking a design and delivering a working, adaptive page.

🔗 **Live-style layout** — open `index.html` to view.

## Highlights

- **Fully responsive** layout, adapted down to mobile screens (the design was reworked and "adapted even more" across iterations).
- **Custom-built UI** on top of Bootstrap 5 — ~470 lines of hand-written CSS with decorative pseudo-elements, hover states, and a consistent brand style.
- **Interactive car gallery** — an image slider/carousel powered by the [Slick](https://kenwheeler.github.io/slick/) plugin.
- Clear conversion-focused structure: hero with call-to-action, a detailed **services** block (purchase, sea delivery, customs, repair, certification, registration), and a **"Why us"** stats section (cars delivered, years on the market, client trust).
- Social and contact links (Instagram, Telegram, WhatsApp, Facebook, phone).

## Tech

- HTML5 / CSS3 (responsive, mobile-first tweaks)
- Bootstrap 5
- JavaScript, jQuery
- Slick carousel

## Running

Open `index.html` in a browser. The Slick assets are bundled in `slick/`.
